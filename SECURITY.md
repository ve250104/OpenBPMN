# Security

Treat interviews, XML, Handoffs, and generated companion reports as potentially sensitive. Do not include private process content or credentials in public issues. Redaction is defense-in-depth, not a guarantee that all secrets are detected.

This repository does not yet advertise a verified private vulnerability-reporting channel. For a suspected vulnerability, avoid publishing exploit details or private material; open a content-free request for a private contact route if needed. No response-time SLA is promised.

The [local trust contract](docs/local-trust-and-file-safety.md) defines the intended safety boundary; [support status](docs/support.md) distinguishes qualified behavior from current development gates. The local CLI does not make the chosen AI host’s inference on-device.
