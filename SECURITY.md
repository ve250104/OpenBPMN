# Security

Treat interviews, XML, Handoffs, and generated companion reports as potentially sensitive. Do not include private process content or credentials in public issues. Redaction is defense-in-depth, not a guarantee that all secrets are detected.

For a suspected vulnerability, use [GitHub's private vulnerability-report form](https://github.com/ve250104/OpenBPMN/security/advisories/new). Private reporting is enabled for this repository. Include the affected version, impact, and a minimal synthetic reproduction; omit credentials and private process material. Do not publish exploit details in a public issue. No response-time SLA is promised.

Read [data and file safety](docs/local-trust-and-file-safety.md) for the safety boundary and [support status](docs/support.md) for current limitations. The local CLI does not make the chosen AI host’s inference on-device.
